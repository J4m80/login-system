# Login System
A simple login and registration system written in Python.

## About
This project is a basic example of how user authentication works.  
It was created as a learning project to practice working with user input, validation, and program logic.

## Features
- User registration
- User login
- Basic user data handling

## Technologies
- Python
- SQLite
